# Supervised Learning , Part 1 

Supervised Learning is making 99% of the economic value made by machine learning, it is used in the majority of machine learning applications. 

Supervised learning algorithms are learning x to y or input to output mappings or labels. 

- The model learns from being given the "right answers" which means suitable output labels (y) for the given inputs (x)

* Examples of Machine Learning Applications : 
    * E-mail filtering
    * Speech recognition 
    * Machine translation 
    * Online advertising 
    * Self driving cars 
    * Visual Inspection 


Example : House Price Prediction 

![image](/course01-supervised-machine-learning-regression-and-classification/week01-introduction-to-machine-learning/02-supervised-vs-unsupervised-learning/images/01-regression.png)

You want to know the price of the house based on its size, so you plot the data on a graph. 

- For example, your friend wants to know what's the price of a 750 square feet house, you draw a line of the data and see the corresponding value. 
- You can decide whether you can fit a straight line or a curve to your data (you'll see how to decide later)

- This type of supervised learning is called Regression which is predicting a number from an infinitely large numbers.
