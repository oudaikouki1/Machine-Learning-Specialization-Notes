- There is a second major type of supervised learning called classification algorithms. 

* Example : Breast Cancer Detection 
    - A machine learning systems that predicts whether a tumor is malignant (dangerous) or benign (safe)
    - Your dataset has tumors of various sizes as well as a diagnosis for their state (benign (0) or malginant (1)) 
    - Plot of the data : 
    [image](/course01-supervised-machine-learning-regression-and-classification/week01-introduction-to-machine-learning/02-supervised-vs-unsupervised-learning/images/02-classification.png)

There are only two possible outputs 0 and 1 

- In classification problems we can have more than two possible output categories 
- In classification : classes = categories 
- Classification predicts categories (doesn't have to be numerical), it predicts a small set of categories/ 
- You can also more than one input to predict an output.

- In classification problems, we use a decision boundary to separate between classes.
