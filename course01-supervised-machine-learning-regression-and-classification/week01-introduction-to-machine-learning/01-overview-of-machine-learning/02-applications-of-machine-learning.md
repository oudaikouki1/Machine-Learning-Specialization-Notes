# Applications of Machine Learning 

In this course you'll learn :
- Machine learning algorithms and how to implement them 
- How to make these machine learning algorithms perform well 

The goal was to build intelligent machines 
- But we found out that there is very few things that we could program explicitly (e.g finding the shortest path between point A and point B used in GPS application) but we could not write explicit programs for much more interseting things like website ranking or voice recognition. 
- The solution was to let the computer learn by itself. 
- Machine learning is going to touch each and every domain.
- Looking further into the future, we want to build machines as intelligent as human beings (AGI - Artificial General Intelligence) 
- According to a study made by McKinsey - machine learning is going to make 13 trillion dollar additional value by the year 2030. 
- Machine learning is already making a tremendous amount of value in software industry and it is expected even more value in other industries such as retail, transportation and automotive
